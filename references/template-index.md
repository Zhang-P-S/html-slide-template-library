# Template Index

Use this file as the top-level map of the skill.

## Purpose

This repository does not start from abstract mood words. It starts from presentation scenarios.

The six stable families are:

1. `academic-defense`
2. `policy-and-governance`
3. `engineering-and-technology`
4. `theory-and-coursework`
5. `innovation-roadshow`
6. `community-portfolio`

Each family has its own reference file. After you identify the main family, read that file before making concrete recommendations.

## Family Selection Hints

### academic-defense

Use when the material is built around evidence, scores, results, certificates, charts, or formal personal or research reporting.

### policy-and-governance

Use when the material needs institutional structure, planning language, policy interpretation, public briefing, or a stronger official tone.

### engineering-and-technology

Use when the material explains systems, mechanisms, architecture, experiments, technical capability, or engineering outcomes.

### theory-and-coursework

Use when the material is concept-heavy, text-led, discussion-led, argumentative, or built on close reading and interpretation.

### innovation-roadshow

Use when the material needs pitch rhythm, launch energy, highlight framing, capability storytelling, or forward-looking momentum.

### community-portfolio

Use when the material behaves like a catalog, gallery, fandom showcase, role atlas, collection, or portfolio browse experience.

## Recommendation Shape

When the task is broad:

- shortlist 3 to 6 directions
- keep one safe default
- keep one adjacent alternate
- keep at most one wildcard

When the task is already clearly inside one family:

- stay within that family unless there is a strong reason to cross over
- only mix a second family if the user’s content truly spans both
