# Innovation Roadshow

Use this family when the deck needs forward motion, product framing, capability storytelling, or pitch-style energy.

## Default Direction

`tech-launch`

## Directions

### tech-launch

- Best for: product launch, competition pitch, project release, capability reveal
- What it looks like: blue-and-white launch framing, strong section rhythm, clear pain-point to solution progression, highlight cards and outcome pages
- Cover syntax: strong title plus project hero visual
- Section syntax: pain point, solution, highlights, outcome, future
- Content grammar: feature cards, solution map, result board, prospect slide
- Preserve: launch energy, clarity, momentum
- Avoid: overloading it with long essay-like text blocks

### outcome-storyline

- Best for: project summary, team showcase, annual innovation narrative, result-led retelling
- What it looks like: lighter base, more narrative progression, stage transitions, outcome-driven rhythm
- Cover syntax: identity plus journey framing
- Section syntax: phase transition with clear progress rhythm
- Content grammar: project timeline, collaboration, stage outcomes, applied value
- Preserve: narrative arc, progress logic, human-readable pacing
- Avoid: turning it into a generic investor deck if the content is really a team or project recap

### black-gold-impact

- Best for: finals, stage demo, climax reveal, high-pressure showcase moments
- What it looks like: high contrast, low-density, oversized statements, stronger stage presence
- Cover syntax: oversized type, high-contrast hero image
- Section syntax: low-density, high-rhythm section dividers
- Content grammar: big-number page, strong-claim page, visual impact page
- Preserve: pressure, focus, command
- Avoid: using it as the default for technical content that actually needs dense explanation
