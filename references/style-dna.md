# Style DNA

Use this file when the user asks to follow the owner's established presentation language instead of a generic template.

## Narrative Defaults

- establish identity and task on the cover
- keep agenda or chapter transitions explicit
- use evidence-heavy middle slides
- end with a closing page that has atmosphere, not just "thank you"

## Visual Defaults

- restrained palettes over flashy gradients
- strong top or bottom framing lines
- real screenshots, charts, diagrams, certificates, and photos over decorative stock
- modular evidence walls are preferred
- medium to high information density is acceptable if the page is clearly segmented

## Copy Defaults

- titles should state the point directly
- avoid slogan-only headings
- keep module labels short
- prefer proof over decoration

## Family Preference Order

When the task is unclear, the owner's defaults usually bias toward:

1. `engineering-and-technology / light-blue-system`
2. `academic-defense / blue-white-evidence`
3. `theory-and-coursework / black-white-argument`

## Negative Defaults

Do not default to:

- generic red academic templates
- generic business-plan templates
- stock-photo corporate decks
- ornamental Chinese-style templates with weak evidence content
